# Getting help

- **A question or an idea**: open a [Discussion](https://github.com/maximeallanic/m3e-gnome-extensions/discussions) (Q&A or Ideas).
- **Something is broken**: open an [issue](https://github.com/maximeallanic/m3e-gnome-extensions/issues/new/choose) with the bug
  report form. The form asks for the details we always need: version, distribution, GNOME version, session type and
  the relevant log.
- **A security problem**: do not open a public issue, see [SECURITY.md](SECURITY.md).

Before you ask, `./verify.sh` (theme) or the troubleshooting page in `docs/troubleshooting.md` answers most
installation problems. This is a volunteer project: answers are best effort, usually within a week.
